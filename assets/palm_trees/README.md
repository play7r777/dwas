# Palm Trees — две лего-пальмы для главного острова (Blender-ассет)

ДВЕ разновидности, **смотрят в разные стороны** — на острове стоят просто две
штучки, без перебора:
- **PalmA** (`palm_a.obj`) — пониже, наклон на восток (+X), 7 листьев;
- **PalmB** (`palm_b.obj`) — повыше, наклон на юго-запад, 8 листьев, крона
  довёрнута на 22°.

Стиль LEGO: ствол из состыкованных сегментов с «юбочками», блочные зубчатые
листья, кокосы, зелёная площадка 4×4 с настоящими шипами, шип на макушке.
~1.5–2k треугольников каждая.

## Файлы
- `palms.py` — генератор сцены (обе пальмы рядом), Blender 4.x.
- `bake_export.py` — оставляет одну разновидность (env `PALM_VARIANT=A|B`),
  джойнит, центрирует площадку в origin (низ на z=0), запекает атлас 1024px
  и экспортирует OBJ+MTL+PNG:
  `PALM_VARIANT=A PREVIEW=1 blender -b --factory-startup -P bake_export.py`
- `palm_a.obj` / `palm_b.obj` + `.mtl` + `_texture.png` — готовые меши.
- `preview_palms.png` — рендер обеих пальм.

## Подключение в игру (Rocket Islands)
1. Studio → **Import 3D** → `palm_a.obj` → MeshPart → переименуй в `PalmA`.
   То же для `palm_b.obj` → `PalmB`.
2. Создай в **ReplicatedStorage** папку `PalmMeshes`, сложи туда PalmA и PalmB.
3. Готово: PlotManager ставит РОВНО ДВЕ пальмы на каждый остров в точках
   `Config.PALMS.SPOTS` (яу разные — смотрят в разные стороны), высота
   масштабируется до `Config.PALMS.HEIGHT` (24 стада).

Пока мешей нет — играют две процедурные пальмы в тех же точках.
