# Текстуры в этой ветке: *.png.b64

API-пуш GitHub умеет только текст, поэтому все PNG (текстуры и превью) загружены
как base64-файлы `*.png.b64`. Превратить их в настоящие PNG — любой способ:

1. **Локально (проще всего):** из корня репы
   ```bash
   python3 tools/decode_textures.py
   ```
   Скрипт раскодирует все `*.b64` в настоящие файлы и удалит `.b64`.

2. **GitHub Actions:** файл `tools/decode_assets.yml` — готовый workflow.
   Скопируй его в `.github/workflows/` и запушь (через API это сделать нельзя —
   нужен workflow-scope), после чего он раскодирует всё сам и закоммитит.

3. **ZIP из чата:** `dwas_v3.3.0_assets.zip` — там все ассеты уже с настоящими
   PNG, можно просто распаковать поверх `assets/`.

После декодирования OBJ+MTL+PNG готовы для Roblox Studio → Import 3D.
