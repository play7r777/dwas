# Air Defense — ПВО-миниган (Blender-ассет + игровая логика)

Лего-турель по референс-скрину: тёмный круглый барабан с шипами, серый
бронированный пьедестал с жёлтой окантовкой и X-раскосами, оливковая
бронебашня с панелями/шипами/ящиком боекомплекта/антенной и ШЕСТИСТВОЛЬНЫЙ
блок минигана.

## Три части с разными пивотами (для анимации)
| Часть | Файл | Пивот |
|---|---|---|
| основание | `air_defense_base.obj` | низ на z=0 |
| башня | `air_defense_head.obj` | центр вращения (yaw/pitch) в origin |
| стволы | `air_defense_barrels.obj` | ось вращения блока в origin |

Стволы в OBJ смотрят по **+Z детали** (в игре код доворачивает на цель).
Числа сборки лежат в `Config.AIR_DEFENSE.MESH` (высота пивота башни, смещение
пивота стволов, bbox-центры частей — Roblox центрирует MeshPart по bbox).

## Файлы
- `air_defense.py` — генератор всей турели, Blender 4.x.
- `bake_export.py` — оставляет одну часть (env `PVO_PART=base|head|barrels`),
  переносит пивот в origin, запекает атлас 1024px, экспортирует OBJ+MTL+PNG:
  `PVO_PART=base PREVIEW=1 blender -b --factory-startup -P bake_export.py`
- `air_defense_{base,head,barrels}.obj/.mtl/_texture.png` — готовые части.
- `preview_air_defense.png` — рендер турели.

## Подключение в игру (Rocket Islands)
1. Studio → **Import 3D** → каждую часть → переименуй в `Base`, `Head`, `Barrels`.
2. Создай в **ReplicatedStorage** папку `AirDefenseMeshes`, сложи туда все три.
3. Готово: AirDefenseManager собирает турель на газоне, башня следит за
   ракетами, стволы крутятся при стрельбе. Пока мешей нет — процедурная турель
   той же формы (фолбэк).

## Как играется (AirDefenseManager.luau)
- Зелёный круг возле турели: наступил — **купил** ПВО ($750), наступаешь ещё —
  **качаешь** до ур.5 (цены растут геометрически).
- ПВО сбивает ТОЛЬКО ракеты, летящие на твой остров, в радиусе
  `Config.AIR_DEFENSE.RANGE` (230 стадов).
- Уровень 1 стреляет МЕДЛЕННО (раз в 1.4с, шанс попадания 18%), уровень 5 —
  почти очередью (раз в 0.3с, шанс 42%). **Может сбить, а может и нет** —
  каждый выстрел бросает кость; промахи видно по искрам мимо ракеты.
- Сбитая ракета взрывается В ВОЗДУХЕ: зданиям урона нет, обоим игрокам
  приходит уведомление.
