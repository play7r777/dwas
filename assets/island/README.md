# Island — лего-острова по референс-скриншоту (Blender-ассет)

Главный остров и под-острова домов в ЛЕГО-стиле, как пол (карта) на скрине:

- **main_island.obj** — главный остров 204×204 стада:
  - рваная песочная кайма из перекрывающихся лего-плит + ступенчатый обрыв в воду;
  - зелёная стад-плита, кольцевая дорога с жёлтым пунктиром, светлые тротуары;
  - вертикальная дорога-перемычка;
  - СЛЕВА газон, СПРАВА бетонная площадка, обведённая **чёрно-жёлтой сигнальной
    лентой** — ЗОНА РАКЕТ (4 стенда: чем дальше, тем крупнее ракета, начиная с
    маленькой — сами ракеты в `assets/rockets/`).
- **sub_island.obj** — под-остров 44×44 в том же стиле (зелёная стад-плита +
  песочная кайма): на таких площадках появляются дома (мостики строит игра).

## Шипы = тайловые текстуры
Геометрические шипы на плитах 200×200 не влезли бы в лимит Roblox
(10 000 треугольников на MeshPart), поэтому **шипы нарисованы в тайловых
текстурах** `tile_*.png` (генерируются самим скриптом через numpy: круглый
шип, светлая макушка, тёмное кольцо, блик). Грид остаётся чётким при любом
масштабе, а весь остров — ~2.8k треугольников. Тайлы общие для main и sub.

## Файлы
- `main_island.py` / `sub_island.py` — генераторы сцен, Blender 4.x. Сами
  создают tile_*.png рядом со скриптом. В превью главного острова стоят
  4 лего-ракеты в зоне (в экспорт не идут).
- `export_obj.py` — джойнит остров, центрирует (низ на z=0) и экспортирует:
  `ISLAND=main PREVIEW=1 blender -b --factory-startup -P export_obj.py`
  `ISLAND=sub  blender -b --factory-startup -P export_obj.py`
- `main_island.obj` / `sub_island.obj` + `.mtl` + `tile_*.png`.
- `preview_main_island.png` / `preview_sub_island.png` — рендеры.

## Подключение в игру (Rocket Islands)
1. Studio → **Import 3D** → `main_island.obj` (тайлы подцепятся сами).
   Переименуй результат в `MainIsland`. То же для `sub_island.obj` → `SubIsland`.
2. Создай в **ReplicatedStorage** папку `IslandMeshes`, сложи туда оба.
3. Готово:
   - PlotManager кладёт MainIsland вместо песчаных цилиндров: ширина
     `Config.ISLAND.MAIN_WIDTH` (205 стадов), верх = ходибельная поверхность.
     `Config.ISLAND.YAW = 90` разворачивает зону ракет на СЕВЕР — точно под
     4 ракетных стенда, газон уходит на юг к спавну, ПВО стоит на газоне.
   - FarmManager кладёт SubIsland под каждый дом (ширина `Config.ISLAND.SUB_WIDTH`).

Пока мешей нет — играют процедурные цилиндры (фолбэк).

Если Import 3D разбил остров на несколько MeshPart по материалам (обычно так и
будет — материалов больше десятка) — просто оставь их в Model с именем
`MainIsland`: код клонирует модель ЦЕЛИКОМ, отмасштабирует через ScaleTo и
поставит по bounding box. То же для `SubIsland`.
