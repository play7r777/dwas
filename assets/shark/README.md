# Shark — акула для открытой воды (Meshy AI «Deep Blue Predator»)

Модель акулы, которая кружит в пустом центре карты, преследует пловцов и
грызёт их в воде (см. `Config.SHARKS`: DPS = 5 → одна акула съедает игрока
со 100 HP ровно за 20 секунд — декорация с зубами, а не настоящий хищник).

## Файлы

- `shark.obj` — меш, децимирован со **147 000** до **9 400 треугольников**
  (лимит Roblox — 10 000 на MeshPart) квадриками с сохранением UV-развёртки.
- `shark.mtl` — материал; `Kd` = средний цвет текстуры, чтобы превью в
  Import 3D было цветным даже до подгрузки текстуры.
- `shark_texture.png.b64` — текстура 1024×1024 (пережата с 2048×2048:
  максимум Roblox — 1024), закодирована в base64 (API-пуш умеет только текст).
  Раскодировать: `python3 tools/decode_textures.py` из корня репы.

## Ориентация меша

Нос акулы смотрит по **-X**, спина по **+Y**, длина 2.0 юнита. Игра
доворачивает меш носом вперёд по движению через `Config.SHARKS.MESH_YAW`
(-90). Если после импорта акула вдруг плывёт хвостом вперёд — поставь
`MESH_YAW = 90`.

## Импорт в Studio

1. Раскодируй текстуры (один раз): `python3 tools/decode_textures.py`.
2. Home → **Import 3D** → `assets/shark/shark.obj` → Import
   (PNG рядом с OBJ подцепится сам). Имя результата (`shark`) не трогай.
3. Перетащи результат в `ReplicatedStorage/Meshes` (или в отдельную папку
   `SharkMeshes` — код ищет и там, и там, и прямо в ReplicatedStorage).

Пока меша нет — играет процедурный фолбэк из партов (чуть крупнее прежнего),
с тем же поведением: круги по своим кольцам, погоня за пловцами, укусы.
